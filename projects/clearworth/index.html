The project

One place for the financial picture.

ClearWorth started as a personal finance project to organize income, expenses, accounts, savings, debt, and financial review in a self-contained Windows application.

The project focuses on connecting the same underlying financial records across useful views: weekly planning, monthly review, annual analysis, and a financial calendar.

It is developed in phases, with testing and refinement as part of the process. This page introduces the project; public downloads will be linked here when a release is published.
