ClearWorthPlanner 1.3.1

Release preparation — public deployment pending. The current website download remains 1.2.1. No 1.3.1 production bank-link availability is claimed.

What changes

  • Readable bank-review cards replace cramped transaction columns, with full dates and amounts, type/category controls, search, filters, inclusion and pagination.
  • Income deposits can have editable names such as Income 1 or a person's paycheck. Names identify existing income; they do not create additional money or scheduled income.
  • Remember category, type and income-name choices for future matching activity. One-time exceptions preserve existing rules.
  • Create an actual ClearWorthPlanner account from bank review, check possible existing accounts and avoid silently merging different accounts.
  • Approve posted bank activity into Actual charts and metrics. Duplicate, pending, refund, transfer and bank-removal safeguards remain.
  • Telephone categories no longer match rent merely because Plaid's category text begins RENT_AND_UTILITIES.
  • The Elko-only pilot is removed. The replacement uses a separate ClearWorthPlanner bank service and email verification, with no developer keys in the desktop app.
  • Existing Documents, guided Alerts, Planning and About features are retained.

Validation completed locally

The working candidate passed 14 source/security/build checks, all 48 functional test entry points, seven broker tests, three main-process client tests, and review-layout checks in two themes at eight widths. These are automated source/service/browser checks. Packaging and automated checks run on Linux; they do not establish interactive Windows or real-bank acceptance.

Before public bank linking

Render must receive access to the private ClearWorthPlanner repository. ClearWorthPlanner-specific server credentials, email delivery, Plaid launch/product configuration and end-to-end acceptance are still required. Free hosting can sleep or pause, so uninterrupted background syncing and prompt revocation retries are not guaranteed. The current service model also requires further work for multiple simultaneous institutions, seamless reconnect, key rotation and operating procedures.

The Windows candidate is unsigned. Installer lifecycle, upgrade/uninstall and live financial workflows still need acceptance for the exact new build. The version number is not a security certification.

Data and separation

Core financial records remain local. The bank service stores encrypted bank connection state and transaction snapshots for recovery and repeat delivery. Disconnect clears the live service state after provider confirmation; previously imported local transactions remain. ClearWorthPlanner has a dedicated database and identity project and does not reuse Tandem's service, data or credentials.

Back up financial data before upgrading. Whole-database encryption is not implied by OS-protected secrets or encrypted bank tokens.
