The project

Small steps. Shared momentum.

Tandem explores how couples can turn intentions into goals they can define, plan, and work toward together. The project combines SMART goal planning with points and levels intended to encourage consistent progress.

The broader aim is practical: help everyday people create their own goals, break them into milestones, and see how individual efforts contribute to a shared journey.

The target platform is iOS and Android. The preview on this page demonstrates the current web interface in a phone-sized layout; a public mobile release has not been linked here.

Project direction

Plan, encourage, and grow together.

The preview demonstrates progress and goal views. The following also describes the requested development scope; it is not a statement that every feature has shipped.

Goals you define

The requested workflow lets couples create their own goals rather than start with predefined goals.

SMART goal guidance

The project is designed around Specific, Measurable, Achievable, Relevant, and Time-bound goals.

Personal & shared goals

The preview includes My goals, Our goals, Partner, and All goals views, connecting individual effort with shared planning.

Points & levels

Shared XP, a progress bar, and a level indicator bring game-inspired encouragement into the goal-planning experience.

Progress at a glance

Active goals, goals achieved, and steps taken appear in the supplied preview alongside shared momentum.

Milestones & calendar reminders

The requested scope includes milestones and goal due dates, with reminders added to the user's preferred device calendar.

Inside Tandem

Two themes. One shared journey.

Light layout

White surfaces, green progress accents, and purple navigation details create a clear view of goals and shared momentum.

Dark layout

Black surfaces retain the same goal cards, XP indicators, and navigation structure with contrasting text and accents.
