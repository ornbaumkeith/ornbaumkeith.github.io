The project

From everyday details to the bigger picture.

ClearWorth began as a self-contained personal finance application for organizing income, recurring expenses, account balances, and financial review. It combines weekly and monthly planning with annual analysis, savings goals, debt tracking, and a financial calendar.

The application is built around local data ownership. Its core workspace runs on Windows, with financial records stored in a local SQLite database. File imports and optional external integrations support the workflow.

ClearWorth Version 1.0.1 brings these workflows together for Windows. The version 1.0.1 unsigned Windows installer is available from the official GitHub Release.

The latest workspace

Plan, organize, and review.

Explore the workflows included in the ClearWorth Version 1.0.1 project. Public installer availability is listed below.

Configurable financial dashboards

Weekly, monthly, annual, and saved custom dashboards bring metrics, charts, filters, and record drill-down together. Add widgets and customize titles, icons, colors, widths, and heights.

Planning Studio

Explore income, expenses, and savings scenarios using weekly, monthly, and annual planning periods, chart-series toggles, editable bars, trend drawing, and saved models. Actual records, planned schedules, and projected scenarios remain distinct.

Savings & debt goals

Plan goal allocations from projected income. Projected savings reduce available cash without being treated as ordinary expenses or changing the actual ledger.

Budget & income allocation

Switch between weekly, biweekly, and monthly reviews, search income and expenses, and inspect payment status. Assign paycheck income to expenses and review saved funding allocations.

Calendar workspaces

Organize income, expenses, events, notes, tasks, and subtasks in named calendars, with Month, Week, Day, List, and Timeline views.

Transactions & expense tracking

Find manual transactions, transfers, contributions, and posted-record corrections under Import → Transactions & Expense Tracking.

Import & reconciliation

Keep planned bulk setup separate from actual transaction imports. Use field mapping, staged review, category changes, and guarded void/restore actions.

Accounts, reports & documents

Review account balances, net worth, financial trends, and reports. Manage documents and attachments through Import.

Financial calculators

Explore pay, tax, retirement, and general calculator categories, inspect calculation explanations, compare employee and contractor scenarios, and save calculations for later review. Estimates depend on entered assumptions.

Guided setup & optional integrations

Follow the six-stage financial workflow guide and searchable Help. Optional Secure Sync and notification providers require separate configuration.

Reports & export

Preview monthly, annual, account, and planning reports. Export supported reports to Excel or CSV and use Print / Save PDF without changing financial records.

Global search

Find accounts, transactions, income, expenses, documents, and related records. Editors search their own records; viewers remain limited to accounts shared with them.

Settings & appearance

Configure accounts, categories, income types, expense statuses, notification providers, appearance, zoom, and the financial workflow guide. Choose light, dark, or Windows theme behavior.

Backup & recovery

Create local backups, configure automatic backup frequency and retention, and validate backups before restoring. Administrator restore creates a safety backup; selective recovery can restore an eligible deleted user or projection year.

Separated application layers

The React interface communicates with desktop services through Electron's preload and IPC boundary. Database work belongs to the application layer rather than direct browser access.

Local financial ownership

The core financial database resides on the Windows installation. File imports, reports, and backup tools support local workflows; optional integrations require their own configuration.

Security & privacy

Protection across the local workspace.

ClearWorth combines local account controls, OS-backed secret storage, and desktop isolation. The latest source retains Argon2id authentication, configurable account controls, and Electron isolation. The details below describe source-level safeguards, not a security certification of the installer.

Protected local sign-in

Local account passwords are hashed with Argon2id. The current password policy requires 12–256 characters; account passwords are not stored in a reversibly encrypted form.

Lockout & session controls

Administrators can configure failed-login lockout thresholds, lockout duration, and session timeout. Administrator password resets require a password change at the next sign-in.

Roles & data ownership

Administrator, Editor, and Viewer permissions are checked in application services and privileged requests. Protected financial changes require the appropriate role, and user data is scoped by ownership.

Windows-protected secrets

Expense website passwords are encrypted with Electron safeStorage in the main process. Notification passwords, OAuth tokens, and webhook secrets use a separate OS-protected provider store outside the finance database.

Desktop isolation

The interface runs with context isolation and sandboxing enabled, and Node integration disabled. Privileged IPC requests validate the sender; unexpected navigation and new windows are blocked.

Account recovery safeguards

Recovery uses hashed, one-time challenges with a 15-minute expiry and limits on invalid attempts. Generic responses help avoid revealing whether an email address belongs to an account.

Safer file workflows

Native file dialogs issue short-lived selection tokens rather than accepting arbitrary paths from the interface. Spreadsheet imports receive file and XLSX-container checks, including limits on expanded content and checks for unsafe entry paths. CSV exports neutralize formula-like text.

OAuth & provider controls

Supported email OAuth flows use Authorization Code with PKCE, S256 challenges, and state validation in the system browser. Slack and Discord webhook URLs are restricted to supported provider endpoints.

Audit & recovery records

Security and recovery activity is recorded in audit logs. Administrative JSON exports omit stored password ciphertext, and full restore creates a safety snapshot with rollback if restoration fails.

Credential handling

Saved expense passwords are not returned to the interface. Copy Password decrypts in the main process and writes to the OS clipboard; the app attempts to clear it after 60 seconds if the copied value remains unchanged.

OS-protected secrets may depend on the Windows profile or computer. Moving data to another profile or machine may require re-entering saved credentials and provider settings.

Scope of protection

OS-backed encryption applies to saved secrets. The project does not document whole-database or whole-backup encryption, so local financial files and backups still need appropriate Windows and storage protection.

Provider authorization and network settings remain part of integration setup. Remote ntfy connections should use HTTPS, especially when authentication is enabled.

Security controls described here reflect reviewed source and interface examples. The 1.0.1 release checks include dependency audits and third-party license verification. These results describe the tested build and can change as new advisories are published. The Windows installer is intentionally unsigned, and this overview does not establish a security certification or an independent penetration-test result.
