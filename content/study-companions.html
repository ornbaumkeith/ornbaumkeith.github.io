The project

One portable study workspace per certification.

Preparing for a technical certification means more than reading a checklist. It takes understanding concepts, knowing when to use them, recognizing common mistakes, and practicing realistic decisions. I created these companions as a more organized way to review Esri certification topics and related ArcGIS documentation.

Each companion is a self-contained HTML file. Its layout, styling, study content, and interactive JavaScript are stored together, so you can download the file, open it in a modern browser, and work through the material without installing an application or creating an account. Links to official Esri documentation require an internet connection.

They are personal, independently developed learning aids, intended to supplement Esri's official Exam Information Guides, training and hands-on practice.

Getting started

Download. Open. Study.

1 · Download your file

Select the purple download button above to save the original .html file from the GitHub release. You can also browse the repository and download a file there.

2 · Open it in your browser

Find the downloaded file in File Explorer or Finder and double-click it. Modern desktop browsers such as Chrome, Edge and Firefox can open these local HTML files. There is no installer or server to configure.

3 · Work through the guide

Start with the exam-domain overview, use the core study guide and technical Q&A, then test your recall with the flashcards and practice exams. Use official Esri reference links whenever a concept needs more detail.

4 · Keep your progress

Browser-saved progress is local to that browser and device, so avoid clearing site data while studying. Where the companion provides export/import controls, save a progress backup before switching computers or browsers.

Tip: To save a copy of the HTML, use the Download button rather than copying the browser page. The HTML itself is the complete study workspace; no ZIP extraction, build step or extra dependencies are needed for ordinary use.

How they were created

Small footprint. Useful functionality.

Technology and packaging

The supplied files use standards-based HTML for content, CSS for responsive layouts and dark/light themes, and JavaScript for the flashcards, exam controls, navigation and browser-based saved progress. Their assets and study material are embedded in each standalone file. No hosted application backend or account is required for core study use.

Documentation and content

The study workspaces were organized around the relevant Esri 2025 exam blueprints and linked official ArcGIS documentation. Each provides independently written review content and practice questions, along with references to look up the underlying technical guidance. Follow the documentation links to verify version-specific behavior as Esri products evolve.

This description explains the technology visible in the supplied HTML files; it does not make unsupported claims about which editor, generation tools, or development services were used to author them.

A note for learners

Independent preparation material.

Created to support learning, not replace official training.

These companions are independent personal study aids, not official Esri training, not affiliated with or endorsed by Esri, and not collections of actual certification-exam questions. Exam versions, blueprints and products can change; always compare with the latest Esri guidance before testing.

Study content runs offline, but official documentation hyperlinks require an internet connection. Notes and progress are stored locally in the browser, not synchronized across devices. Features may differ slightly between the four files.
